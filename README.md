# Ecolixeira
lixeira inteligente que utiliza sensores para abertura automática e monitoramento do nível de resíduos, promovendo mais higiene, praticidade e sustentabilidade no descarte do lixo.

### 🧠 Inteligência Artificial
Adicionado um script de Machine Learning (scikit-learn) para manutenção preditiva. Ele usa Regressão Linear sobre os dados do sensor ultrassônico (HC-SR04) para prever o momento exato em que a lixeira precisará ser esvaziada.
